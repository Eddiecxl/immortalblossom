# v4.2.11 · 随局而应

固定的观察/消息/打坐/道路/等待按钮已移除。作者在同一次 JSON 给出 choices，不另开 AI 请求；parseNarration 保留，世界回合和自动余波都在接受当前事实后写入 flags.playerChoices。只保存最多四条普通说话/动作草稿及真实 targetIds。地点/分钟变化、人物死亡离开、物品归属/用途/有效交付变化会重新校验；无有效作者选项时，从实际最后一拍、在场人物、待交付物、伤药、旅途和道路给出后备选择。点击 speech 填说话，action 填动作，不自动落笔或同意，不泄露未来剧情。自由输入始终保留。纯文案的机械语义仍不能被完整自然语言证明，作者建议不是权威历史。

astra-local-interaction 是跨名字/seed 的严格完整子句编译器：已支持的亲身接触、姿态/手势及自然时长直接生成真实 experience.record，不需要云端。截图的双段亲吻指令、同类拥抱/牵手/挥手等不因配额停止效果结算。名字来自当局世界，代词逐句解析；不歧义时才确定目标。所有子句均被理解才走本地，混合未实现的机械/情绪/历史改写必须整体交给语义规划，禁止只执行前半句。并发与顺序混用的复杂时序目前保留给语义作者，不随意截短。

durationMinutes 和 startsAfterMinutes 记录每段真实起止，NPC计划在持续接触期间不能先行离场，不代表改写其性格/同意/好感。原有分钟级 scheduler 用 ceil 推进，秒级指令的精确时长仍记录在经历中。只有与本轮时钟一起结算的本地编译上下文可登记持续区间，模型不能凭未来经历冻结人物。世界仍按真实耗时推进，后续人物反应走 v4.2.10 的已保存子事务，不再次收费或增加玩家回合。

未能本地完整理解、仍需云端的言灵，如果进入真实202/429队列，保留未提交输入和同一事务ID，自动续接；界面不再反复弹回“可再次发动”。刷新/返回可见窗口继续处理，存档UI/字幕/其他回合占用时延后；分支或输入变更取消旧重放，玩家也可明确撤回。进入 engine_commit 后禁止承诺撤回，避免已经保存却说未发生。未提交敕令不算已经生效，更不虚写新规则来冒充100%自由语义执行。

供应商真实配额、停机与未知新概念不能靠删提示消除。此版减少本地能算的云请求，保留可追踪自动排队，并不承诺任意自然语言都已有机械规则或云端永不等待。供应商锁定、SQLite/schema6、原图/音乐、用户模型与存档保持。最终发布证据见 Maintenance/Verification/v4211-release-state.json。
