# v4.2.8 快对白与动态故事账本

用户要求快速且连续的小说式RPG：有闲聊/休息/了解/梳理，也有重大行动；已有大纲只是世界起点，玩家可拒绝、破坏或改道，后果进入后续。本文区分已实现能力与后续工作，不能承诺免费API无限快速。

## 快速互动

游戏默认 fastDialogue:true。纯发言优先 astra-dialogue 的小作者视图及短提示，通常一至两句人物对白，最多一小段有用动作；不强制重复任务、催促或危机。普通短交流推进1分钟，代替旧5分钟；真实到期事件仍结算。实际世界与校验包完整保留，不靠截断玩家输入或改存档提速。

视图保留真实听者、伤势/修为、现有持物与承诺、有关任务、近期相关记忆和故事记录。作者不携带每条数据库编号及全部背景。明确回顾、重要依赖、自定义规则、动作/战斗、刚发生的重大改写等使用原完整通道；不能为变快丢掉核心约束。作者视图在旧7000字节阈值之前建立，避免大型世界的无关资料先阻断简单对白。

Maintenance/Verification/v428-fast-play 真Groq连续4轮：1975、1157、1184、17340毫秒；前三轮各1请求，第四轮2请求，暴露了旧social.observe语义标签禁止中文标点的问题。已允许安全的短自由语义文本，仍校验实际听者、当前证据与数值范围。邀约实测又暴露地点别名与明日日期错误，已加入唯一真实地名解析和Engine日历换算。以上是样本，不能宣称所有回合都在1秒内或真实配额不再存在。

## 可计算的故事线索

astra-story 为 invitation/plan/clue/foreshadow 保存稳定ID、实际提出人、地点、相关实体、开始/最晚时辰、条件、公开范围与状态历史。worldPlan 的 story.propose/respond 与其他操作同事务落账；新邀约是pending，不能替玩家同意，剪掉否定词也不能制造同意。

relative time:{dayOffset,hour,minute,durationMinutes} 由Engine换算为绝对世界时刻，跨日日期不能与说明相反。开始与期限进入现有事件队列，长时间等待不会跳过整个会面。答应不等于赴约：人物须实际存活、没有在途、到达实际地点并满足时刻/条件。拒绝/撤回、错过时辰、主人死亡或场所毁坏更新对应计划；已终止的邀约不能换一句对白重开。线索不会只因提供者死去就被抹掉，私下计划只在实际揭示条件满足后进入公开作者视图。

变化追加history与因果事件、相关人物记忆。故事ID可用于既有受限条件表达式，故能作为任务/规则依赖；下一轮作者读取真实状态，从结果继续，不把计划当成已发生事件。完整checkpoint仍由原SQLite/浏览器/云端机制保存，新数据不是额外独立AI记忆，也不额外调用一个导演模型。任务面板可查看全部公开邀约与线索、实际状态、人物与时辰。

## 尚未实现的完整目标

当前不是可自动重算任意100小时历史的完整事件溯源系统。言灵仍能按已实现原子操作改当前世界并影响未来，但“让过去从未发生并重算全部记忆/血缘/交易”尚不能保证；不能通过改写一段回忆伪称实现。AI也还不能在普通叙事中任意新建可破坏的建筑/新实体，现有场景居民发现与言灵创造仍受各自来源规则约束。后续应扩展有来源的世界发现、NPC行程和有修订来源的历史重算，不按单一鸿门宴写特例。
