`v420-cloud-law-saves`：独立seed、凡人境界、明确言出法随让自己无敌，Engine直接结算且没有叙事API请求；三个手动档保存/读回，等待后回到手动档会建立新旅程分支，未来行记不混入；刷新保留已结算无敌状态。设置仅默认云端Groq，提供官方Key链接。

`v420-cancel-resume`：在同一真实会话取消等待，世界不提交；重新打开游戏后原话和事务编号恢复。再发送时读取原来的云端job，最终446→451分钟，仅一个generate POST。为可靠看到取消按钮，实验只延后客户端首个状态轮询；上游生成和最终回复均为真实Groq。
