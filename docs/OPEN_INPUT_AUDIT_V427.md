# v4.2.7 开放输入阻断审计

2026-11-09 用户要求排查会让游戏行不通的内容，尤其落笔长等及“不符合剧情”的错误拒绝。跳舞、跑题、玩笑、改道都必须被世界接住；不按seed路线不是无效输入。普通行为的真实后果与言灵改写分开，不能以开放输入之名凭对白伪造死亡、物品归属、任务或同意。

## 确认并修复的阻断

1. **场内移动被当成地图旅行。** 旧解析遇到“走向/前往”就要求地图道路，“走向林小满跳舞”“前往门边敲门”在请求AI之前报错。游戏的playable策略下，命中实际道路才结算旅行，其他场内/开放动作交给作者；实际在途者不能被瞬移回起点。隔空攻击仍不造成远处伤害，但尝试与原因可以进入当前场面。
2. **引用被当成叙事视角错误。** 旁白中的人物引语含“你”会整轮失败。现在先区分引语，保留第一人称要求；游戏中仅剩轻微视角问题时记录诊断并允许已验证的互动继续。
3. **谈论死人被判成死人正在说话。** 回忆、愿望、过去话语及提到尸体容易被全文关键词命中。校验现区分过去/假设与当前断言、发言主体；实际死者dlg和未落账复活仍不允许。
4. **文风问题触发多次云请求。** 重复布景、残缺空句、内部数值和泛泛结尾可使整轮回滚。playable模式可删除这些有问题的段落，重新核验剩余真实回应；仅在确有有效互动时提交。不会用预制NPC对白替代AI，也不会把格式失败或无效世界操作伪称成功。
5. **提示重复消耗输入额度。** 合并主角视角、回合交接等重复指令，保留完整作者事实、玩家原话、关联操作说明与长期存档。失败文案明确是AI后续与事实冲突，不归咎玩家输入；校验细节保留为diagnostics供维护。

回归覆盖引用、死者回忆、愿望、同句中的真实死者发言、场内移动、跳舞、删除重复段落、事实冲突保留原世界。继承既有全套物品/交锋/死亡/承诺/存档测试。正式发布状态以 Maintenance/Verification/v427-release-state.json 为准。

## 仍需区分的限制

免费云API仍有真实配额和服务可用性，不能无上限调用；Gemini 3.8此前高负载/超时问题没有因此被宣称解决。AI提出的无效世界操作仍需修正，否则不得写坏存档。当前主线不是完整100小时成品；本轮不是对所有可能自然语言都已验证。后续继续扩展可组合引擎操作和按需记忆，不按单个seed写特例。
