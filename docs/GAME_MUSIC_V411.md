# v4.1.1 · 此世长歌

用户指定的 Music 四首 MP3 原样复制为 game/assets/audio/luoxian 中的 wish、battle、music、loop.mp3。不得替换原始 Music 文件，不得把新的游戏曲目用于 launcher。

game/beta4/game-soundtrack.js 是游戏独立曲目目录。进入游戏窗口，加载与 Logo 开始时播放若还能见你；开场与封面共用同一个顺序列表：若还能见你 → 打斗版 → 音乐版。开场结束、跳过 Logo、显示封面不能重新播放第一首。封面久留时该列表循环。

从封面进入游戏 UI，在 entry veil 覆盖下实际展示游戏的时刻，切换到 loop版，然后音乐版、打斗版，再回到 loop版，一直循环。危机状态不重排歌曲。回到封面重新开始开场列表；重看开场与封面共用列表。手动下一首也淡入淡出，旧 source 在衔接结束后真正停止并断开，不得无限叠播。

共享 audio.js 通过显式 playlists、initialScene、smoothManual 选项实现上述流程；不传选项的 launcher 继续使用 soundtrack.js 的原始六首配乐、原切歌方式及游戏运行时的停播锁。曲间使用至多3秒的等功率交叉淡化，先解码再衔接；场景变化作废旧的加载任务，防止迟到解码播放错误曲目。字幕、音效、音量、后台静音及用户设置保留。

Logo 是约8.2秒的程序化绘制演出：黑底、流动水墨轨迹、绘制金色星轨、印记与片名揭示、尘光和宽银幕黑边，之后约0.85秒渐隐到原有视频封面。尊重减少动态与低特效设置，仍可跳过，不用新的静态照片替代动画。

本次仅修改游戏音乐、开场演出和版本公告；不更改世界引擎、AI、存档、模型或凭据。

验证：8项新增音频行为测试，完整143项 Node 回归通过。隔离 Chromium 使用真实游戏页面与 createExperience，实测开场→封面不断曲、手动顺序、实际进入游戏换 loop、循环及淡化后仅剩一个 source；四首 MP3 均成功解码，长度依次368.760、177.534、184.774、203.974秒，双声道。预览使用独立临时配置和无存档测试接口，不调用 AI。浏览器截图检查了 Logo 与封面，设备端实际听感仍需玩家体验。
