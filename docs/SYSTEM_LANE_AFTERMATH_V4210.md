# v4.2.10 · 侧耳有声，敕令有回响

系统台词保留在同一顺序 blocks 里作为播放时机标记，画面只放到左侧 systemFeed。播放到对应一拍才逐字显示，随后继续人物/旁白；历史重建不再往正文重复添加 sys。完整存档里的未来台词不能提前显示。

正式言灵按钮使用独立 invocation 标记，不因问号、凡人境界或模型擅加的普通行动前提失效。明确有条件的改写仍尊重原指令条件，目标/范围/实际资源与字段校验保持。完整 JSON 中合法可执行的 worldPlan 独立于可选文案；坏旁白、空 blocks 不能否决有效言灵。截断 JSON 和无可执行提案仍不伪造成功，保留原输入待处理。

autoAftermath 模式下，本地可执行言灵/重大动作先结算保存，随后自动写人物余波。语义言灵同一次回复可包含实际效果和人物回应；缺少目标人物回应时持久保存 flags.pendingAftermath，由 UI 自动续接，不需要玩家补一句落笔。旁人的回复不能替代被触及人物的反应；代词按实际焦点与不歧义在场者解析，不凭空猜远方目标。

后续子事务有稳定 parentTurnId、phase:aftermath、独立幂等ID和 transactionJournal；不再推进世界分钟、玩家回合、言灵次数或原代价。只允许普通社会/约定/任务/剧情计划反应，不能重放施法/移动/赠物。保存修订 CAS 拒绝旧异步结果覆盖新分支；写行记中断后恢复 journal，不重找 AI。真实排队复用原 job；终止的失败 job 才换 generation，避免永久卡在同一死任务。刷新续玩/恢复可见窗口会继续待续回应。无效反应只做有界自动重试，侧栏也可手动接续；免费服务额度仍可能等待。

非数值的接触、手势、姿态、感受，可用 reality-only experience.record 保存 occurred 事实、真实 actor/target IDs、分钟/地点及精确原指令 evidence，进入因果事件、实际目击者记忆和作者召回。任务条件可引用经历实体。该通道不能替代已有生命/境界/移动/资源字段操作，禁止冒充 death 等机械操作和越范围人物；可选 claims 必须与真实状态一致。自由描述仍不是完整自然语言证明器，不承诺所有新概念已有可执行规则或任意过去重算。

维护范围：没有改配额调度、主世界seed、存档 schema6、SQLite、封面、美术、音乐、供应商锁定或用户模型/存档。实际发布证据位于 Maintenance/Verification/v4210-release-state.json；未出具 complete 状态前不能把实现等同全部发布验证完成。
