# 开放输入与阻断审计

用户授权全面排查使游戏行不通的内容，优先落笔长等待及错误的剧情拒绝。舞蹈、离题、玩笑、冒犯和奇怪动作均可尝试；NPC可惊讶/拒绝配合，普通动作受真实处境影响；言灵按明确范围实际生效。剧情路线不能作为拒绝输入的条件。

实现方向：先复现校验误报和修复请求放大。修正引用/回忆被当成当前事实、把名字中“你”当视角变化；游戏模式下轻微文风问题仅记录，不拖住已校验有效操作，事实和所有权/死亡/同意/范围仍由Engine负责。生成提示明确区分玩家自由、NPC回应和机械结算。不得把用户输入当成错误文本，也不以假对白掩盖服务故障。

- [ ] 跨场景输入、引用/回忆、元叙事拒绝和长修复请求回归。
- [ ] 引擎/作者提示/校验层修复，保留原话及真实后果。
- [ ] 实际Groq多轮正常/荒诞动作及存档恢复，记录耗时与修复次数。
- [ ] 全部测试、公开代码和本地/网页发布；若外部AI服务失败，清楚记录未通过项。
