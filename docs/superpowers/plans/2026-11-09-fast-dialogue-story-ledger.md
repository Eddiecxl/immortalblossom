# v4.2.8 快对白与动态故事账本

用户授权：减少免费API下落笔长等，允许短对白；叙事包含闲谈、休息、了解与回顾，玩家选择可改当前/未来，历史记录可被显式言灵改写并追溯。不能继续每轮携带全部重型资料或强推任务。保留完整数据库与世界校验，不造假响应、不轮换锁定供应商躲配额。

设计：普通纯发言优先快速作者视图，保留听者、实际身份/修为/伤势、相关记忆、当前持物/承诺与提及依赖；需要广泛回顾、战斗、复合动作或复杂规则时使用完整视图。同次请求仍可提出实际操作。短对白减少指令/输出额度，时间按短交谈推进，不自动重演紧急提示。情节轻重写入当前节奏，不以每句结尾再推任务为义务。

故事账本补齐计划/邀请/伏笔的提出、玩家回应、期限、前置条件和终止；人物死亡、场所毁坏、拒绝和到期改变对应未来记录。必须可计算真实状态，公开与隐秘信息分别召回，不能将计划当事实。改写既有世界仍用原子worldPlan；历史重写保留原记录和修订来源，不能只改一句旁白当作已重算全部过去。

- [ ] 请求成本/节奏及关联依赖测试；快速视图不截断输入、不丢同意/所有权约束。
- [ ] 快对白提示、短时间与轻重节奏；完整回顾/大动作通道保留。
- [ ] 通用故事账本与期限/依赖失效，相关记忆/作者召回。
- [ ] 实际连续对白与拒绝/破坏/赴约测试，完整回归与发布；如不能消除真实免费限额，记录实测上限，不虚报全部瞬发。
