# v4.2.3 可回应的遭遇与改写余波

用户授权直接优化全部 seed 的开局和每回合参与感；沿用已有引擎、存档、世界自由度与云端队列，不再请求重复设计确认。

采用有状态的现场遭遇：开局在初始世界推进后建立真实第一次相遇，记录人物位置、事件、记忆与待回应局面；既有旧档不重置。后续从刚发生的对白与动作接续，不重复派发同一问题。不用私下目标或道路提示代替场景。固定全局主线会限制玩家自由；仅改提示词不能修空场与保存，故采用引擎场景状态配合原有单回合作者。

- [ ] 红绿回归：空场新 seed、起始条件覆盖、开局重入、旧档死者/行程不重置、首次相遇不重复。
- [ ] 开场：穿越与系统、当场遭遇、具体待答/待行动点；多种种子场景，保留拒绝、离开和不用言灵的玩法。
- [ ] 持续场景：真实参与者、已说过的话、玩家输入与改变存入 flags.playerScene；死亡/离开/世界终局关闭旧场景，失败事务不推进。
- [ ] 言灵/抵达：由真实前后世界差异提供余波事实，一次作者请求表现重大转折；不捏造受伤、房屋归属、围观群众。收拢重复结算、伤势与道路传闻。
- [ ] 作者：先回应玩家，再推进一小拍交回玩家；不透露尚未知晓的 NPC 私事，不强迫接受提议。
- [ ] 验证：多 seed 结构检查、完整 SQLite 回归、真实云端拒绝/离题/瞬移/突破试玩；保存恢复点。
- [ ] 发布：4.2.3、本地、补丁/完整包、GitHub 和 Cloudflare；保留所有旧数据。

高风险输入：只说“哈咯”；拒绝帮助；连用言灵杀死/传送现场人物；等待跨越相遇/行程事件；JSON/429 重试。对这些检查世界与场景一起提交，未成功时不伪造回合。
