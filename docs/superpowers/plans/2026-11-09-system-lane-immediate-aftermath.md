# v4.2.10 左栏系统与自动余波

按用户已授权的玩法修复直接实施；保留现有存档、固定供应商、真实物品/战斗/因果和v4.2.9额度修复。

设计：sys在同一有序blocks中仅作为时间标记，不进入中央正文DOM；播放器到达这一拍便在左栏逐字显示，再继续下一段，不等整回合结束。普通动作也解析实际受影响人物作为回应对象；言灵提案一旦完整合法，文案瑕疵不得使已实现效果失败。

已知本地言灵仍立即事务提交；将待续余波与必要的施法前快照一起保存，随后自动调用作者，不需要新玩家输入。语义言灵可在原请求中给出即时人物反应；不足时同样生成待续余波。后续作为独立、幂等、同世界时刻的aftermath记录提交，不再次施法、收费、增长玩家回合数或覆盖新进度。刷新恢复待续记录；额度等待保留同一job自动续接，失败只影响文案，不回滚言灵。

开放接触/姿态等没有现成数值字段的结果，增加通用experience.record事实，关联真实actor/targets、地点、来源与记忆；不能代替生死、修为、物品等已有机械字段。仍由Engine检查真实字段，拒绝错误提案而非因偏离seed拒绝输入。不得用虚构成功掩盖未知能力或真实API不可用。
